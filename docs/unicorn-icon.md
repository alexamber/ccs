The current source is the user's replacement image supplied on 2026-11-17,
described by the user as generated artwork and authorized for use in CCS.

## Provenance and publication

The user represents the replacement as copyright-free. Its generation history
and third-party rights have not been independently verified; AI generation by
itself does not establish copyright clearance or exclusive ownership.

The earlier images were derived from VectorStock image **29057706**,
[Unicorn head icon symbol](https://www.vectorstock.com/royalty-free-vector/unicorn-head-icon-symbol-vector-29057706),
by **abdie11**. Those files have been replaced in the working tree. Earlier local
commits on the local `feat/terminal-session-titles` branch still contain the old
assets. Publish only the clean `feat/terminal-session-ui` branch, whose feature
commit is based directly on the prior main revision and excludes those old blobs.

VectorStock's [license agreement](https://www.vectorstock.com/faq/membership-content-license-agreement-281086)
does not grant MIT sublicensing rights to its artwork. Recoloring, background
removal, or a close recreation of that work would not by itself resolve the
original rights issue. If the replacement was generated by closely adapting the
stock image, clearance or an independently designed mascot remains appropriate.
